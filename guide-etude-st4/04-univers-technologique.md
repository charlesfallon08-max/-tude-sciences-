# ⚙️ Univers technologique

> Comment on **conçoit, représente et fabrique** des objets techniques. Quatre grands thèmes : le langage des lignes, l'ingénierie mécanique, l'ingénierie électrique et les matériaux. C'est aussi la base de l'**analyse technologique** (section C de l'épreuve).

---

## 1. Le langage des lignes (dessin technique)

### Les types de lignes
| Ligne | Apparence | Sert à… |
|---|---|---|
| **Ligne de contour vu** | trait plein épais | les arêtes visibles |
| **Ligne cachée** | trait pointillé/tiret | les arêtes non visibles |
| **Ligne d'axe** | trait mixte (tiret-point) | le centre d'une pièce/d'un trou |
| **Ligne de cote** | trait fin avec flèches | indiquer une mesure |
| **Ligne d'attache** | trait fin | relie la cote à l'objet |

### Les projections
- **Projection à vues multiples** : représente l'objet par ses vues (face, dessus, côté/profil). Précise mais pas en 3D.
- **Projection isométrique** : représente l'objet en **3 dimensions** (vue en perspective). Les axes forment des angles de **120°**.

### Autres notions
- **Échelle** : rapport entre le dessin et l'objet réel.
  - **1:1** = grandeur réelle • **1:2** = réduit 2× • **2:1** = agrandi 2×
- **Cotation** : indication des **dimensions** sur le dessin.
- **Coupe** : on « scie » l'objet pour montrer l'**intérieur** (hachures sur la matière coupée).
- **Section** : montre seulement la surface coupée.
- **Développement** : « mise à plat » d'un objet (ex. patron d'une boîte).

## 2. L'ingénierie mécanique

### Les fonctions mécaniques élémentaires
- **Fonction de liaison** : assemblage de deux pièces. Caractéristiques :
  - **Directe** (sans intermédiaire) / **indirecte** (avec vis, colle…)
  - **Rigide** / **élastique**
  - **Démontable** / **indémontable**
  - **Complète** (aucun mouvement) / **partielle** (un mouvement possible)
- **Fonction de guidage** : dirige le mouvement d'une pièce (en translation, en rotation…).

### Les systèmes de TRANSMISSION du mouvement
> Le mouvement reste du **même type** (ex. rotation → rotation).

| Système | Description |
|---|---|
| **Roues de friction** | deux roues en contact |
| **Poulies et courroie** | reliées par une courroie |
| **Engrenages** (roues dentées) | dents qui s'engrènent (sens inverse) |
| **Roues dentées et chaîne** | comme un vélo |
| **Roue dentée et vis sans fin** | grande réduction de vitesse |

- **Roue menante** : celle qui **entraîne**. **Roue menée** : celle qui est **entraînée**.
- Plus une roue menée est **grande** (plus de dents), plus elle tourne **lentement**.

### Les systèmes de TRANSFORMATION du mouvement
> Le mouvement **change de type** (ex. rotation → translation).

| Système | Transformation |
|---|---|
| **Vis et écrou** | rotation → translation |
| **Came et tige (galet)** | rotation → translation (va-et-vient) |
| **Bielle et manivelle** | rotation ↔ translation |
| **Pignon et crémaillère** | rotation → translation (ex. direction d'auto) |

- **Adhérence / frottement** : résistance au glissement entre deux surfaces.

## 3. L'ingénierie électrique

### Les fonctions électriques
| Fonction | Rôle | Composante |
|---|---|---|
| **Alimentation** | fournir l'énergie | pile, batterie |
| **Conduction** | laisser passer le courant | fil conducteur |
| **Isolation** | empêcher le courant de passer | gaine, plastique |
| **Protection** | couper si surcharge | **fusible, disjoncteur** |
| **Commande** | ouvrir/fermer le circuit | **interrupteur** |
| **Transformation de l'énergie** | convertir l'électricité | moteur, ampoule, DEL, résistance |

### Les interrupteurs (commande)
- **Unipolaire** : coupe **un** fil. **Bipolaire** : coupe **deux** fils.
- **Unidirectionnel** : une position. **Bidirectionnel** : dirige le courant vers deux chemins.

### Transformations de l'énergie (exemples)
- Moteur : électrique → **mécanique**
- Ampoule/DEL : électrique → **lumineuse** (+ chaleur)
- Résistance/grille-pain : électrique → **thermique**
- Pile : chimique → électrique

## 4. Les matériaux

### Les contraintes (forces appliquées)
| Contrainte | Effet |
|---|---|
| **Traction** | étire (tire dans 2 sens opposés) |
| **Compression** | écrase |
| **Flexion** | plie/courbe |
| **Torsion** | tord (vrille) |
| **Cisaillement** | coupe (forces décalées) |

### Les propriétés mécaniques
| Propriété | Définition |
|---|---|
| **Dureté** | résistance à être rayé/pénétré |
| **Élasticité** | revient à sa forme après déformation |
| **Ductilité** | s'étire en fil sans casser |
| **Malléabilité** | s'aplatit en feuille |
| **Ténacité** | résiste à la rupture |
| **Résilience** | résiste aux chocs |

### Les familles de matériaux
| Famille | Exemples | Caractéristiques |
|---|---|---|
| **Bois et bois modifiés** | pin, contreplaqué, MDF | léger, renouvelable |
| **Métaux et alliages** | acier, aluminium, laiton | conducteurs, résistants |
| **Matières plastiques** | thermoplastiques (refondables), thermodurcissables (non) | légères, isolantes |
| **Céramiques** | verre, porcelaine | dures, cassantes, résistent à la chaleur |
| **Matériaux composites** | fibre de verre, fibre de carbone | combinent les avantages de plusieurs matériaux |

### Dégradation et protection
- **Dégradation** : usure, **corrosion** (rouille du fer), pourriture du bois.
- **Protection** : peinture, vernis, **galvanisation** (couche de zinc), huile, anodisation.

### La fabrication
Étapes : **mesurage et traçage** → **usinage** (couper, percer, limer) → **formage** (plier) → **assemblage** → **finition**.

## 🛠️ Méthode — réussir l'analyse technologique

Devant un objet ou un schéma, pose-toi ces questions :
1. **Quelle est la fonction de chaque pièce ?** (liaison, guidage, conduction…)
2. **Quel type de mouvement ?** (rotation ou translation)
3. **Transmission ou transformation ?** (même type de mouvement = transmission)
4. **Quelle pièce est menante / menée ?**
5. **Quel matériau et pourquoi ?** (relie une propriété à son usage)

**1.** Dans un dessin technique, une **ligne cachée** est représentée par :
- a) un trait plein épais   b) un trait pointillé   c) un trait mixte   d) une flèche

**2.** Une projection qui représente l'objet en **3 dimensions** est dite :
- a) à vues multiples   b) isométrique   c) en coupe   d) développée

**3.** Une échelle de **2:1** signifie que le dessin est :
- a) grandeur réelle   b) réduit 2×   c) agrandi 2×   d) réduit 10×

**4.** Le système **vis et écrou** transforme un mouvement de :
- a) rotation → rotation   b) translation → translation   c) rotation → translation   d) aucun mouvement

**5.** Un système d'**engrenages** est un système de :
- a) transformation du mouvement   b) transmission du mouvement   c) liaison   d) isolation

**6.** Quelle composante assure la fonction de **protection** d'un circuit ?
- a) la pile   b) le fil   c) le fusible   d) le moteur

**7.** La contrainte qui **étire** un matériau est :
- a) la compression   b) la traction   c) la flexion   d) la torsion

**8.** Un matériau **malléable** peut :
- a) s'étirer en fil   b) s'aplatir en feuille   c) revenir à sa forme   d) résister aux rayures

**9.** Dans un système de transmission, la roue qui **entraîne** les autres est la roue :
- a) menée   b) menante   c) folle   d) dentée

**10.** La rouille du fer est un exemple de :
- a) galvanisation   b) corrosion   c) usinage   d) élasticité

**11.** Une liaison qui ne permet **aucun mouvement** entre deux pièces est dite :
- a) partielle   b) complète   c) élastique   d) démontable

**12.** Un **moteur** électrique transforme l'énergie électrique en énergie :
- a) thermique   b) lumineuse   c) mécanique   d) chimique
